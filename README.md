### Core Engineering Invariants

Every testing harness, automated pipeline, and agentic workforce I build adheres to four foundational engineering principles:

* **Adversarial Consensus (No Self-Grading):** An execution agent never audits its own work. Verification is divided into decoupled, role-specific consensus gates (Orchestrator → Analyst → Designer → Reviewer) to eliminate false-positive test passes.
* **Zero-Mutation Database Safety:** Read-only inspection invariant for live transactional environments. Automated verification operates strictly via read-only `SELECT`, schema extraction, and execution plan analysis—guaranteeing zero data corruption risk.
* **Cryptographic Evidence Integrity:** Every captured screenshot, HTTP response payload, query result, and system log is stamped with an immutable SHA-256 hash for forensic traceability.
* **Strict 4-Tier Defect Taxonomy:** Clear, non-inflated categorization across all deliverables: `Blocker` (service inoperable), `Major` (critical business flow broken), `Minor` (non-blocking edge case), and `Trivial` (cosmetic misalignment).
